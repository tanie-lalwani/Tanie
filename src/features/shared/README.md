# Shared Layout & SEO Feature Module (Boilerplate)

Global application shell, responsive navigation, footer, error boundary, and structured JSON-LD metadata head components.

## Included Components
- **Navbar**: Responsive floating dock with language toggle, sound FX, route highlights.
- **SiteFooter**: High-contrast footer with social handles, copyright, and instant quote links.
- **AppShell**: Root layout container with glassmorphic backdrop.
- **SEOHead**: Dynamic meta tags, OpenGraph, Twitter cards, and Schema.org rich snippets.

## Copy-Paste Usage in Any Project
```tsx
import { AppShell, Navbar, SiteFooter, SEOHead } from "@/features/shared";
```
