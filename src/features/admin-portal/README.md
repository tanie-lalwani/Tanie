# Admin CRM & Lead Management Feature Module (Boilerplate)

Centralized agency & freelancer administrative command center.

## Included Capabilities
1. **Live Lead Pipeline**: Real-time incoming leads feed, live status updating (`New`, `Contacted`, `Proposal Sent`, `Won`, `Archived`).
2. **Project & Reel Management**: Add, update, and reorder case studies and video reels without touching code.
3. **Custom Quotation Review**: Inspect client calculated custom packages, feature selections, and discount totals.

## Copy-Paste Usage in Any Project
```tsx
import { AdminPortalView } from "@/features/admin-portal";

export default function AdminPage() {
  return <AdminPortalView />;
}
```
